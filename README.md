Beginner AR app using Unity with joystick movement and animations

Features: • Image Tracking • 3D Charizard Model • Character Animation • Android APK Build

How to Use:

Install the APK on Android
Allow Camera Permission
Point the camera at the target image
Watch the 3D model appear and animate
Technology: • Unity • C# • AR Foundation / Vuforia
